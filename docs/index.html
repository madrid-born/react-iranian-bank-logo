Iranian Bank Logos for React & Next.js

Free Iranian Bank SVG Icons & React Components

مجموعه‌ای رایگان از لوگو و آیکون بانک‌های ایرانی با فرمت SVG، مناسب برای استفاده در پروژه‌های React و Next.js.

Use Iranian bank logos directly in your React and Next.js applications with the react-iranian-bank-logo package.

لوگو بانک های ایرانی

در این صفحه می‌توانید لوگو و آیکون بانک‌های ایرانی را مشاهده کنید. برای دریافت نام هر لوگو، روی آن کلیک کنید. این آیکون‌ها به صورت SVG ارائه شده‌اند و می‌توانید از آن‌ها در پروژه‌های وب، داشبورد، فروشگاه اینترنتی، اپلیکیشن‌های مالی و پروژه‌های فین‌تک استفاده کنید.

لوگو بانک های ایران برای React

پکیج react-iranian-bank-logo مجموعه‌ای از لوگوهای بانک‌های ایرانی را به صورت کامپوننت React در اختیار توسعه‌دهندگان قرار می‌دهد.

این کتابخانه برای پروژه‌های React و Next.js طراحی شده و استفاده از لوگوهای بانک‌های ایران را در رابط کاربری ساده می‌کند.

Usage (React)

The package exports a lightweight React component for rendering Iranian bank logos. 

import { IranianBank } from "react-iranian-bank-logo";

export default function App() {
    return (
        <div>
            <IranianBank name="ir-mellat" size={40} />
            <IranianBank name="ir-pasargad" size={30} />
        </div>
    );
}

Available Bank Icons

The library includes SVG logos for popular Iranian banks. New bank logos may be added over time.

React & Next.js Package

Install the package from npm: 

npm install react-iranian-bank-logo
